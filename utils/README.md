# Utilitaires

Ce dossier contient des fonctions utilitaires pour le projet.

## Fonctions disponibles

- `helpers.py`: Fonctions utilitaires générales
  - `ensure_dir()`: Création de répertoires
  - `validate_file_exists()`: Vérification de l'existence de fichiers
  - `get_file_extension()`: Extraction d'extension de fichier
  - `filter_points_by_height()`: Filtrage de points par hauteur
  - `calculate_iou_2d()`: Calcul IoU pour bounding boxes 2D
